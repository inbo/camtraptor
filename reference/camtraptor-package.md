# camtraptor: Explore and Visualize Camera Trap Data Packages

Explore and visualize Camera Trap Data Packages ('Camtrap DP',
<https://camtrap-dp.tdwg.org/>). camtraptor offers a step-by-step
workflow to read Camtrap DP files, filter data of interest, summarize
information (e.g. number of observed species) and visualize this per
deployment on an interactive map. You can also use it to transform data
for analysis in 'camtrapR'.
