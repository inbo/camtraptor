# Check a data frame is output of `summarize_observations()`.

Check a data frame is output of
[`summarize_observations()`](https://inbo.github.io/camtraptor/reference/summarize_observations.md).

## Usage

``` r
check_summary(grouped_df)
```

## Arguments

- grouped_df:

  A grouped tibble data frame as returned by
  [`summarize_observations()`](https://inbo.github.io/camtraptor/reference/summarize_observations.md).

## Value

If no error, `TRUE`.
