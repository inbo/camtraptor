# Read the Camtrap DP example dataset

Re-export of
[`camtrapdp::example_dataset()`](https://inbo.github.io/camtrapdp/reference/example_dataset.html).

## Usage

``` r
example_dataset()
```

## Value

Camera Trap Data Package object.

## See also

Other read sample data functions:
[`mica`](https://inbo.github.io/camtraptor/reference/mica.md)

## Examples

``` r
example_dataset()
#> A Camera Trap Data Package "camtrap-dp-example-dataset" with 3 tables:
#> • deployments: 4 rows
#> • media: 423 rows
#> • observations: 549 rows
#> 
#> And 1 additional resource:
#> • individuals
#> Use `unclass()` to print the Data Package as a list.
```
